# GreenDen

GreenDen is a simple, friendly website for a plant shop. It shows off a range of natural and artificial plants, with a clean green look that works on phones, tablets, and computers.

## What's inside

The site has three pages:

- **Home**: A welcome banner, a short "About Us" section, best-selling plants, customer reviews, and a newsletter sign-up box.
- **Products**: A grid of all the plants for sale, with a search bar at the top.
- **Contact**: A simple form for sending a message to the shop.

Every page shares the same top menu and footer, so moving around feels smooth.

## Things I like about it

- Looks good on any screen size
- The menu stays at the top while you scroll
- Plant photos lift slightly when you hover over them
- Soft green colors and the Outfit font give it a calm, fresh feel

## Built with

- HTML
- [Tailwind CSS](https://tailwindcss.com/) for styling
- [Google Fonts](https://fonts.google.com/) (Outfit)

No installation is needed, since Tailwind and the font load from the internet.

## How to run it

1. Download or clone this project.
2. Make sure there is an `images` folder next to the HTML files with your plant photos (`img_1.jfif`, `img_2.jfif`, and so on).
3. Double-click `index.html` to open it in your browser.

## Project structure

```
GreenDen/
├── index.html      (Home page)
├── product.html    (Products page)
├── contact.html    (Contact page)
└── images/         (Plant photos)
```

## Good to know

This is a design-first project, so a few parts are for show right now:

- The search bar, contact form, and newsletter box don't send or search anything yet.
- The mobile menu icon doesn't open a menu yet.
- Text and prices are placeholders.
